ARP8 — acoustic arpeggiator

2026 · web midi · javascript

A browser MIDI arpeggiator for Korg Berlin's phase8 — the eight-voice acoustic synthesizer with steel resonators. Twenty-eight hand-authored generative compositions (Bach, Reich, Eno, Pärt, Cage, Satie…), each a different musical territory using one engine. Runs in Chrome over Web MIDI — no installer, no DAW.
